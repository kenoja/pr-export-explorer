# Puerto Rico export complexity

Working directory for exploring Puerto Rico's export data.

## Quick look
- Open **`pr_exports.html`** in any browser. It works offline and needs no installation.
- It shows two linked charts of Puerto Rico's exports, 2003–2024:
  1. **Exports by industry:** one row per industry, one bubble per product and year.
  2. **Exports by product complexity (PCI):** the same bubbles, placed by complexity.
- **Click a bubble or search a product** to highlight it in both charts (Esc resets).
- **Exports to:** switch between all destinations, foreign countries or the U.S.
- **Industry buttons** (chart 2): show or hide industries, or show only competitive products (RCA ≥ 1).

## Files
| File | What it is |
|---|---|
| `pr_exports.html` | The visualization (generated by `build.py`) |
| `scripts/download_data.py` | Downloads the raw data |
| `scripts/build.py` | Builds the dataframe and the visualization |
| `scripts/template.html` | Layout and interactions of the visualization |
| `data/pr_exports.csv` | The dataframe: one row per product per year |
| `data/raw/iepr/pr_exports_hs4.csv` | Puerto Rico exports by product, year and destination |
| `data/raw/atlas/products_hs92.csv` | Product list: code, name, sector |
| `data/raw/atlas/product_year_hs92.csv` | World exports and PCI per product per year |

## How to run
1. Open a terminal in this folder.
2. Create a Python environment: `python -m venv .venv`
3. Install the packages: `.venv\Scripts\python.exe -m pip install pandas requests plotly` (Mac/Linux: `.venv/bin/python`)
4. Optional, refreshes the raw data (about 5 minutes): `.venv\Scripts\python.exe scripts\download_data.py`
5. Rebuild the dataframe and the visualization: `.venv\Scripts\python.exe scripts\build.py`
6. Open `pr_exports.html` in a browser.

## Data sources
- **Puerto Rico exports:** Puerto Rico Institute of Statistics (IEPR), detailed external trade database ([link](https://apps.estadisticas.pr/iepr/Publicaciones/Proyectosespeciales/ComercioExterno.aspx)).
  - Monthly data from July 2002, by product and destination country.
  - Built from U.S. Census Bureau records, including shipments to the U.S.
- **World trade and product complexity (PCI):** Atlas of Economic Complexity, Harvard Growth Lab ([link](https://atlas.hks.harvard.edu)).
  - HS92 4-digit products, 1995–2024.
